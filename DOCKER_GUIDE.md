# Saknny Docker Deployment Guide 🚀

This guide provides instructions on how to spin up the **Saknny Backend** and **PostgreSQL Database** using Docker and Docker Compose.

## Prerequisites

- [Docker](https://docs.docker.com/get-docker/) installed on your machine.
- [Docker Compose](https://docs.docker.com/compose/install/) (usually included with Docker Desktop).

## Quick Start

To spin up the entire backend infrastructure, run the following command from the project root:

```bash
docker-compose up -d --build
```

This will:

1. Build the backend image using the `backend/Dockerfile`.
2. Pull the PostgreSQL 15 image.
3. Start the database container (`saknny_postgres`) on port `5433`.
4. Start the backend container (`saknny_backend`) on port `8000`.

## Services Overview

| Service      | Container Name    | Port (Host:Container) | Description            |
| ------------ | ----------------- | --------------------- | ---------------------- |
| **Database** | `saknny_postgres` | `5433:5432`           | PostgreSQL 15 database |
| **Backend**  | `saknny_backend`  | `8000:8000`           | FastAPI Backend API    |

## Common Commands

### Stop the services:

```bash
docker-compose stop
```

### Stop and remove containers/networks:

```bash
docker-compose down
```

### View logs:

```bash
docker-compose logs -f
```

### Restart the backend only (after code changes):

```bash
docker-compose restart saknny_backend
```

### Access the database via CLI:

```bash
docker exec -it saknny_postgres psql -U saknny_admin -d saknny
```

## Troubleshooting

- **Port Conflict**: If port `5433` or `8000` is already in use, you can change the host port in the `ports` section of `docker-compose.yml`.
- **Database Connection**: The backend is configured to connect to `saknny_db:5432` inside the Docker network. If you are running the backend locally (not in Docker) but the database is in Docker, use `localhost:5433` in your `.env` or `config.py`.
- **Volume Persistence**: Database data is persisted in a Docker volume named `saknny_pgdata`.
