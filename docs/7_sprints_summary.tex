\section{Executive Summary}
% ══════════════════════════════════════════════════════════════════════

The Saknny Intelligent Housing Portal is a full-stack web application designed to digitize the end-to-end student housing lifecycle at Benha University's Shoubra Faculty of Engineering. The project was executed over \textbf{seven agile sprints}, encompassing \textbf{29 frontend pages} (15~student, 14~admin) backed by \textbf{13 RESTful API modules} exposing over \textbf{45 endpoints}.

The system spans the complete housing journey: from student registration, document verification, and enrollment approval, through housing catalog browsing, application submission, room allocation, lease generation, and digital contract signing, to billing and payment processing, residency check-in/checkout, maintenance ticketing, messaging, announcements, surveys, and administrative analytics with immutable audit logging.

\subsection{Technology Stack}

\begin{longtable}{p{4cm}p{9cm}}
\toprule
\textbf{Concern} & \textbf{Technology} \\
\midrule
Frontend Framework & Next.js 16 (App Router), TypeScript \\
Styling & Tailwind CSS v4 with \texttt{@theme} design tokens \\
Fonts & Manrope (headlines) + Public Sans (body) via \texttt{next/font/google} \\
Icons & Material Symbols Outlined (variable font) \\
API Layer & Custom \texttt{apiClient} with JWT \texttt{Bearer} authentication \\
Backend & Python 3.12, FastAPI, SQLAlchemy ORM \\
Database & SQLite (development), designed for PostgreSQL migration \\
Authentication & JWT (HS256) stored in \texttt{localStorage} \\
Internationalization & Custom \texttt{useTranslation} hook (English + Arabic) \\
\bottomrule
\end{longtable}

\section{Sprint-by-Sprint Implementation}
% ══════════════════════════════════════════════════════════════════════


% ── Sprint 0 ──────────────────────────────────────────────────────────
\subsection{Sprint 0: Infrastructure \& Shared Shell}

\textbf{Objective:} Establish the foundational layout components, navigation, routing, and design system before any feature work begins.

\subsubsection{Deliverables}

\begin{itemize}[leftmargin=2em]
    \item \textbf{DashboardSidebar} -- Responsive sidebar with role-based navigation links using \texttt{usePathname()} active-state highlighting.
    \item \textbf{DashboardNavbar} -- Top navigation bar with user avatar, language toggle, and session controls.
    \item \textbf{Admin Layout Shell} (\texttt{/admin/layout.tsx}) -- Separate sidebar for administrators with 14 menu items.
    \item \textbf{Dashboard Stepper} -- Real-time document-phase derivation from \texttt{GET /students/\{id\}/documents}.
    \item \textbf{i18n Infrastructure} -- Dual-locale JSON files (\texttt{en.json}, \texttt{ar.json}) with 260+ translation keys.
    \item \textbf{Design Token System} -- \texttt{globals.css} with \texttt{@theme} tokens: \texttt{primary}, \texttt{surface}, \texttt{shadow-soft}, status colors.
\end{itemize}


% ── Sprint 1 ──────────────────────────────────────────────────────────
\subsection{Sprint 1: Student Profile}

\textbf{Objective:} Allow authenticated students to view and update their personal information.

\begin{longtable}{p{3.5cm}p{9.5cm}}
\toprule
\textbf{Page} & \texttt{/dashboard/profile} \\
\textbf{API Endpoint} & \texttt{PUT /students/\{student\_id\}/profile} \\
\textbf{Features} & Editable form fields (Name, Home City, Preferences), pre-filled from user session data, success/error banner feedback, full i18n support. \\
\bottomrule
\end{longtable}


% ── Sprint 2 ──────────────────────────────────────────────────────────
\subsection{Sprint 2: Housing Catalog \& Applications}

\textbf{Objective:} Enable students to browse available housing, submit applications, and track their status.

\begin{longtable}{p{3.5cm}p{3.5cm}p{6cm}}
\toprule
\textbf{Page} & \textbf{Route} & \textbf{Key Features} \\
\midrule
Housing Catalog & \texttt{/dashboard/catalog} & Building grid with gender/status filters; room table with bed availability color coding (green/yellow/red). \\
Apply & \texttt{/dashboard/apply} & Enrollment-gated form; preferred building dropdown; notes textarea. \\
My Applications & \texttt{/dashboard/applications} & Status-pill cards (submitted/under\_review/approved/rejected/waitlisted); waitlist join action. \\

\subsection{Sprint 3: Admin Document Verification \& Application Review}

\begin{longtable}{p{3.5cm}p{3.5cm}p{6cm}}

\textbf{Page} & \textbf{Route} & \textbf{Key Features} \\

\begin{longtable}{p{3.5cm}p{3.5cm}p{6cm}}
